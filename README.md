# GPS_Burim_Akco
# Выбор лучшего генотипа пшеницы по совокупности признаков - анализ полевого опыта по 6 генотипам пшеницы (5 селекционных линий HU и контрольный сорт Ayalon) и выбор лучшего генотипа HU по совокупности признаков продуктивности и качества зерна.
По каждому генотипу измерены длина, ширина, площадь, соотношение сторон, масса 1000 семян(TKW) и содержание белка в зерне(GPC), с несколькими повторами. Нужно выявить лучший генотип среди линий HU.
# Методы, которые использовались в анализе
Paзведочный анализ данных(EDA)
Дисперсионный анализ (ANOVA)
Post-hoc тест Тьюки(Tukey HSD)
Многокритериальное ранжирование (TOPSIS)
# Результат
Между линиями HU не было выявлено статистически значимых различий по ключевым признакам продуктивности (GPC, TKW), следовательно лучший генотип  определен методом многокритериального ранжирования. По результатам содержания белка и массы зерна лидирует генотип HU-7.
# Технологии, которые использовались в анализе
Python, pandas, lumpy, matplotlib, seabird, scipy, statsmodels.
